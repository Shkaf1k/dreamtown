DREAMTOWN — Cozy 3D Island Builder
=================================

Запуск:
1. Распакуйте архив.
2. Откройте папку проекта в терминале.
3. Запустите локальный сервер, например:
   python -m http.server 8000
4. Откройте http://localhost:8000

Важно: Three.js загружается как ES-модуль с CDN, поэтому нужен интернет.
Открытие index.html напрямую (file://) может блокироваться браузером.

Управление:
- Выберите инструмент слева и нажмите на остров, чтобы разместить объект.
- Перетаскивайте мышью/пальцем пустую область для вращения камеры.
- Колесо мыши или pinch двумя пальцами — масштаб.
- Undo отменяет последнее действие.
- Save / Load сохраняют и загружают города в LocalStorage.
- Export / Import работают с JSON-файлами.
- На телефоне панель инструментов расположена внизу экрана.

Сохранения хранятся локально в браузере на текущем устройстве.
